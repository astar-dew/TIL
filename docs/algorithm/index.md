# Algorithm

알고리즘과 자료구조 개념, 그리고 문제 풀이 기록을 정리합니다.

## 구성

- [Concepts](./concepts/index.md): 알고리즘과 자료구조의 개념, 동작 방식, 복잡도 분석
- [Problems](./problems/index.md): 코딩테스트 문제 풀이와 접근 과정 기록

개념과 풀이는 글의 성격과 쌓이는 속도가 달라 나누어 관리합니다. 개념은 최신순, 문제 풀이는 번호순으로 정렬됩니다.

## Topics

- 정렬, 탐색
- 자료구조 (배열, 연결 리스트, 스택, 큐, 트리, 힙, 해시)
- 그래프 (BFS, DFS, 최단 경로, 위상 정렬)
- 동적 계획법
- 그리디, 분할 정복, 백트래킹
- 시간 복잡도와 공간 복잡도
