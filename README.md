# TIL

개발 공부 내용을 정리하는 개인 기술 블로그 저장소입니다.

## 목표

- 학습한 내용을 주제별로 정리합니다.
- 문제 해결 과정과 트러블슈팅 기록을 남깁니다.
- GitHub Pages를 통해 Markdown 문서를 블로그처럼 볼 수 있게 관리합니다.

## 카테고리 구조

```text
TIL
├── web
│   ├── frontend
│   ├── backend
│   ├── database
│   └── infra
├── app
├── cs
├── devops
├── language
├── projects
└── interview
```

## 작성 규칙 초안

- 하나의 글은 하나의 주제를 다룹니다.
- 파일명은 가능하면 영문 소문자와 하이픈을 사용합니다.
- 날짜가 중요한 학습 기록은 `YYYY-MM-DD-topic.md` 형식을 사용합니다.
- 단순 개념 정리는 `topic.md` 형식을 사용할 수 있습니다.
